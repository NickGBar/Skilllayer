# Review Packet V0

Экспериментальный локальный Markdown-отчёт на основе Git и переданных receipts. Не запускает проверки и не принимает решения о merge. Скрипт доступен из исходного checkout; в установленную CLI-команду он пока не включён.

```bash
python scripts/review_packet.py --repo /path/to/repo --base origin/main \
  --head HEAD --gate-receipt /path/to/gate-receipt.json \
  --verify-receipt /path/to/verify-receipt.json > review-packet.md
```

Оба receipt необязательны. Без них результаты проверок не подтверждены. Gate receipt используется только при совпадении контрольной суммы, head и merge base. Контрольная сумма без независимой проверки подписи не доказывает происхождение. Verify receipt показывается только как заявленный контекст: наличие head в нём не доказывает, что проверенное рабочее дерево соответствует коммиту. Команды и подробности остаются в исходном receipt.

Пакет содержит пути файлов; receipts могут содержать локальные пути, команды и другой чувствительный текст. Просматривайте материалы перед передачей. Результат `passed` не гарантирует правильность кода или отсутствие дефектов.
