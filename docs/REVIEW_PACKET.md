# Пакет для ревью

Локальный Markdown-отчёт для человека, который смотрит изменение: что изменилось (по git) и
какие проверки выполнены (по расписке гейта, если она относится к этому изменению). Команда
не запускает проверки и не принимает решения о merge.

```bash
skilllayer review-packet --base origin/main --head HEAD \
  --gate-receipt gate-receipts/<файл>.json \
  --verify-receipt <verify-receipt>.json --lang ru --output review-packet.md
```

Обе расписки необязательны. Без них пакет прямо пишет, что результаты проверок не подтверждены.

- **Расписка гейта** используется, только если совпадают её контрольная сумма, head и merge
  base. Если задан `SKILLLAYER_RECEIPT_KEY`, проверяется и подпись: пакет пишет «контрольная
  сумма и подпись совпадают», а неподписанная или чужая расписка не принимается. Без ключа
  контрольная сумма не доказывает, откуда расписка.
- **Расписка verify** показывается только как контекст: она не доказывает, что проверенное
  рабочее дерево соответствует коммиту.
- Команды и подробности остаются в исходной расписке.

Пакет содержит пути файлов; расписки могут содержать локальные пути, команды и другой
чувствительный текст. Просматривайте их перед передачей. Результат `passed` не гарантирует
правильность кода или отсутствие дефектов.

`--lang en` даёт тот же пакет на английском; по умолчанию язык берётся из `$SKILLLAYER_LANG`,
затем английский. Код выхода `1`, если пакет собрать не удалось (например, ref не найден).
